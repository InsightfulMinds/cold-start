# cold-start

Deployable AI operating systems for small teams. Each folder is a self-contained system you can drop into a Claude project and run in a day.

## What's here

| Folder | Client | Context |
|---|---|---|
| [diana-agency-os](./diana-agency-os/) | Diana — boutique real estate team, Austin TX | Client deployment |

## Philosophy

These aren't demos. They're built to hand to someone who didn't build them.
If a new team member can't get operational in a day without a call, the system failed.
